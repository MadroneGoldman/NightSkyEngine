# WitchGame

This project uses the shared WitchTools plugins. Before working on them, on Night Sky battles or on anything that builds or runs the editor, read `SharedPlugins/WitchTools/CLAUDE.md`. Since the 2026-11-23 merge the WitchTools repo lives in `SharedPlugins/WitchTools` (WitchToolsBattle and WitchToolsEnv are found through `AdditionalPluginDirectories` in `WitchGame.uproject`; the engine ignores such directories inside `Plugins/`), and Night Sky Engine and Narrative Pro are real folders in `Plugins/`, with no junctions. The NSE git repo's root is this folder.
