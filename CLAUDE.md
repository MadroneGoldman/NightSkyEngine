# WitchGame

This project uses the shared WitchTools plugins. Before working on them, on Night Sky battles or on anything that builds or runs the editor, read `SharedPlugins/WitchTools/CLAUDE.md`. Since the 2026-11-23 merge the WitchTools repo lives in `SharedPlugins/WitchTools` (the repo holds the WitchTools, WitchToolsBattle and WitchToolsEnv plugin folders side by side, found through the single `AdditionalPluginDirectories` entry `SharedPlugins` in `WitchGame.uproject`; the engine ignores such directories inside `Plugins/`, and overlapping entries crash project-file generation), and Night Sky Engine and Narrative Pro are real folders in `Plugins/`, with no junctions. The NSE git repo's root is this folder.
